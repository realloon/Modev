# Modev

Modev is a toolkit designed for RimWorld mod development.

## Features

- Skip the upload confirmation wait.
- Exclude files or folders from uploads.
- Bundle all Defs into a single XML file on upload.
- Remove comments from XML files on upload.

All of the above features are toggleable.

## Development

- In `DEBUG` builds, the confirm action exports the processed upload folder to your Desktop.
